# Student Course Registration System

A full-stack web application built with **MongoDB**, **Express.js**, **React.js**, and **Node.js** (MERN stack).  
This system allows students to register for courses dynamically based on department and semester.

## 🚀 Features

- Student registration and login
- Department and semester-based course listing
- Dynamic form handling
- REST API backend
- MongoDB database integration

## 🛠️ Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Styling: CSS/Tailwind/sweetalert2

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/narmadha-17/student_course_registration_system.git
cd student_course_registration_system

# Install backend dependencies
cd backend
node server.js

# Install frontend dependencies
cd ../frontend
npm install
